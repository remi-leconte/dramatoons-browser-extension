# Dramatoons Highlighter

Extension navigateur de [Dramatoons](https://dramatoons.ovh), pour Firefox et les navigateurs Chromium : elle surligne, sur n'importe quel site, les titres des webtoons de la bibliothèque du lecteur, avec sa note et son dernier chapitre lu.

En cours de création (version 2.5.0, alignée sur celle du site).
